# Trimistry-UI 💈

A modern **unisex salon website** built using HTML and CSS. Trimistry provides a clean and responsive interface where users can explore salon services, book appointments, submit feedback, and get in touch with the salon.

### Features

* 🏠 Home section with salon introduction
* 📅 Appointment booking form
* ⭐ Customer feedback form
* 📞 Contact section with salon details
* 🧭 Navigation bar with smooth section linking

### Technologies Used

* HTML5
* CSS3

### Purpose

This project was created to practice **HTML structure, forms, navigation, semantic elements, and CSS styling** while building a real-world website concept.
